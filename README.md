 🏨 Hostel Management System

A comprehensive web-based Hostel Management System developed using **Python** and **Django** to streamline hostel operations such as room allocation, student management, bookings, and online payments.

🚀 Features

* 🔐 Secure User Authentication and Authorization
* 👨‍🎓 Student Registration and Management
* 🏠 Hostel and Room Management
* 🛏️ Room Booking and Allocation
* 💳 Online Payment Integration using Razorpay
* 📋 Booking History and Status Tracking
* 🛠️ Admin Dashboard for Managing Hostel Operations
* 📢 Complaint and Query Management
* 📱 Responsive and User-Friendly Interface

🛠️ Tech Stack

Frontend

* HTML5
* CSS3
* Bootstrap
* JavaScript

Backend

* Python
* Django

Database

* SQLite / PostgreSQL

Payment Gateway

* Razorpay

⚙️ Installation

Clone the Repository

```bash
git clone https://github.com/theerthakrishna555/Hostelmanagement.git
cd Hostelmanagement
```

Create Virtual Environment

```bash
python -m venv venv
```

Activate Virtual Environment

 Windows

```bash
venv\Scripts\activate
```

 Linux / macOS

```bash
source venv/bin/activate
```

Install Dependencies

```bash
pip install -r requirements.txt
```

Run Migrations

```bash
python manage.py makemigrations
python manage.py migrate
```

Start Development Server

```bash
python manage.py runserver
```

Visit:

```bash
http://127.0.0.1:8000/
```
